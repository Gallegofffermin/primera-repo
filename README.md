
### COMANDOS de GIT

## git init 
crea el repositorio localmente

## git add 
añade los cambios de los archivos selecionados al commit

## git commit -m "mensaje" 
crea el commit con el mensaje

## git push 
puseha todos los commits a la nube

## git status 
muestra el estado de git, commits, archivos, y si esta al dia.
